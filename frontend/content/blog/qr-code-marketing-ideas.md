A QR code campaign fails for one of three reasons: nobody saw the code, nobody had a reason to scan it, or the page it opened was not worth the scan. Every idea below is chosen because it clears all three, and each comes with a tracking note, because a code you cannot measure is just a decoration.

Two ground rules apply to all of them. First, use a dynamic code, so the destination can be changed after the thing is printed and so scans are counted at all; [static vs dynamic](/blog/static-vs-dynamic-qr-codes) explains why a static code can do neither. Second, one code per surface. Two flyers with the same code teach you nothing; two flyers with two codes tell you which one worked. On QRly there is no per-code fee, so there is no reason to economise on codes.

## Print

**1. The offer flyer.** A flyer whose code opens a specific offer, not the home page. The reason it works is that the offer is the reason to scan; the flyer is just the delivery mechanism. Track: scans per thousand printed, and set an expiry date on the link so the offer ends itself. [Coupons and discounts](/blog/qr-code-for-coupons-and-discounts) covers the mechanics.

**2. The direct-mail letter.** A code in the top corner that opens a page pre-filled for the recipient segment (new-mover, lapsed customer, neighbour of a recent job). Works because it turns a letter into a landing page without asking anyone to type. Track: one code per segment, so the response rates can be compared.

**3. The business card that stays current.** A code to a contact page rather than a printed email address that will be wrong in two years. Track: scans by month tell you whether the cards you handed out in March are still being used in June. [Business card codes](/blog/qr-code-for-business-card) has the detail.

**4. The magazine or newspaper ad.** A code that opens the product page for that ad, on a code used nowhere else. Works because print advertising has never had a response mechanism cheaper than this. Track: scans per insertion, by city, by day; the [print advertising post](/blog/qr-codes-for-print-advertising) explains what that data can and cannot tell you.

## Packaging

**5. The instructions that update.** A code on the box that opens the current instructions, assembly video or FAQ. Works because the printed leaflet is out of date the moment the product changes; the code is not. Track: scans by day-of-week and hour, which tell you when people actually open the product.

**6. The reorder code.** On a consumable — coffee, filters, ink — a code that opens the reorder page for that exact product. Works because the moment of running out is the moment of intent. Track: scans against reorders placed.

**7. The registration or warranty card.** A code that opens the registration form with the product model pre-filled in the URL. Track: completion rate; if scans are high and registrations low, the form is too long. [Product packaging](/blog/qr-code-for-product-packaging) has more on durability and placement.

**8. The provenance story.** Food, drink, craft goods: a code that opens the page about where this batch came from. Works because people who buy these things want the story, and it does not fit on a label. Track: scans by country, which for exported goods tells you where the product actually ends up.

## In-store

**9. The shelf talker.** A small card at the shelf edge with a code that opens the product's reviews, a comparison or a demo video. Works because it answers the question a customer would otherwise ask an absent assistant. Track: scans per SKU, which is a direct read on which products people hesitate over. The [retail post](/blog/qr-codes-for-retail-stores) covers the whole shop floor.

**10. The receipt review code.** Printed on the receipt, opening the review form directly. Works because the customer is at peak goodwill and holding a phone. Track: scans against reviews; the [Google reviews post](/blog/qr-code-for-google-reviews) has the direct-link details.

**11. The window after closing.** A code on the door or window that opens the online shop, the booking page or the menu, for the person who turned up and found you shut. Track: scans by hour; if most come after 6 pm, the window is doing a job the shop cannot.

**12. The loyalty sign-up.** A counter card opening the sign-up form. Works when the benefit is stated on the card in one line. Track: sign-ups per scan; unique visitors per day tells you how many distinct people tried, not how many times a phone was waved.

## Outdoor

**13. The parked van.** A code at eye height on the side panel, opening a contact page with a tap-to-call number. Works when the van is parked outside a job for hours; fails on the back doors in traffic. Track: scans by city and hour, which map to where the van was.

**14. The estate agent board.** A code that opens that property's listing, with photos and the booking link for a viewing. Track: scans per property; a board that gets scanned but produces no viewings has a listing problem. [Real estate signs](/blog/qr-code-for-real-estate-signs) covers size and weatherproofing.

**15. The poster with a deadline.** Gig, market, open day: a code that opens ticketing, with the link set to expire on the day so a poster left up afterwards shows an expired page rather than selling tickets to a past event. Track: scans by location, which show which posters were seen. [Flyers and posters](/blog/qr-code-for-flyers-and-posters) has the print-size working.

## Events

**16. The booth banner.** A code that opens a lead-capture form or the deck, on a banner large enough to scan from the aisle. Track: scans by hour tell you when the hall was busy and whether the code was visible at all. The [trade show post](/blog/qr-codes-for-trade-shows-and-conferences) goes into what the analytics say the next morning.

**17. One code per talk.** A code on the last slide, opening the slides and a follow-up form, different for each session. Works because the audience wants the slides and would otherwise ask by email. Track: scans in the ten minutes after the session versus later, which tell you whether the slide was up long enough.

## Digital-to-print

**18. The video end-card.** A code on the last five seconds of a video shown on a screen — a waiting room, a trade show loop, a TV spot — opening the page the video was about. Works because the viewer has a phone and the video has just told them why. Track: referrer is empty on a real camera scan, so these are distinguishable from clicks on the same link shared online. [UTM parameters](/blog/qr-code-utm-parameters-google-analytics) covers tagging the destination so the scan shows up in your own analytics too.

## What to look at afterwards

A dynamic code records the scan at the redirect: the time, the approximate location (city-level, from IP, so treat it as a rough read), the device and OS, and whether there was a referrer. It does not record who the person was, and QRly does not run any script on their phone or set a cookie; [the privacy page](/privacy) lists every field.

That is enough to answer the questions that matter for a campaign:

| Question | Where the answer is |
|---|---|
| Did anyone see it | Total scans per code |
| How many people, not how many scans | Unique visitors, counted per day |
| Where was it seen | City and region, as an approximation |
| When was it seen | Hour and weekday heatmap |
| Which version worked | One code per version, compared side by side |
| Did they do the thing | Scans against conversions on your own side |

The last row is the one no QR platform can answer alone. Scans measure attention; what happens after the redirect is measured on your page. [Measuring print ROI](/blog/measure-print-campaign-roi-with-qr-codes) covers joining the two.

## Frequently asked

**Do I need a different QR code for every campaign?**
For every surface you want to compare, yes. A code is free to make, and the only way to learn that the flyer beat the poster is for them to have different codes. On QRly, [make a code](/create) per surface and name each for where it went.

**Can I reuse a QR code from an old campaign?**
If it is dynamic, yes: change the destination and the printed code follows. This is the main reason to prefer dynamic codes for anything printed in volume. [Reusable QR codes](/blog/reusable-qr-code) discusses when that is a good idea and when a fresh code is cleaner.

**What should the page behind the code look like?**
Mobile, fast, and about the one thing the code promised. A code that promises a discount and opens a home page with a banner somewhere below the fold loses most of its scanners in the first three seconds.

**How big should a marketing QR code be?**
Around 2 cm for anything handheld, larger with distance. The [size guide](/blog/qr-code-size-guide) has the rule of thumb and the working behind it.

**Can I tell which scans came from print and which from a link shared online?**
Partly. A camera scan arrives with no referrer; a click from a chat app or a web page usually has one. Beyond that, use a separate code for print and a plain link for digital, and the split is exact.
